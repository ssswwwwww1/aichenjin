# 首都文旅数字平台

本项目是"AI赋能于传统文化传承"主题的创新创业竞赛网站，融合了AI、AR、社区互动等多种功能，助力中华优秀传统文化的数字化传承与创新体验。

## 主要功能
- **智能体验模块**：AR景区导览、3D复原、语音讲解等
- **文化学习模块**：多媒体课程、知识文章、互动体验
- **亲子社群与UGC**：社区动态、圈子、活动、内容分享
- **个性化推荐**：学习计划、兴趣标签、成就系统
- **用户中心**：学习记录、收藏、评论、成就、消息通知

## 技术栈
- 前端：React + Ant Design + React Router + Axios + Three.js + AR.js + A-Frame
- 后端：Node.js + Express + (可扩展为MongoDB等)
- 其他：Socket.io、TensorFlow.js、二维码、Markdown等

## 启动方法
1. **安装依赖**
   ```bash
   npm install
   ```
2. **启动后端服务**
   ```bash
   npm run server
   ```
3. **启动前端开发环境**
   ```bash
   npm start
   ```
4. **一键同时启动前后端（推荐）**
   ```bash
   npm run dev
   ```

前端默认端口：`3000`  后端API端口：`5000`
